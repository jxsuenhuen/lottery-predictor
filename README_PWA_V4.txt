Lottery Predictor PWA V4

New features:
- Save the next-period prediction when the user taps Predict.
- Store prediction records in localStorage.
- When an actual draw is entered, automatically settle the matching prediction by position hits (0-7) and exact-7 flag.
- Show Top 10 candidates.
- Show probability distribution 0-9 for each of 7 positions.
- Show cumulative real forward-prediction backtest metrics.
- Export history CSV and prediction CSV.
- Reset both history and prediction log to initial state.

Upload the files in this folder to the root of the GitHub Pages repository.
The service worker cache version is v4; after deployment, if iPhone still shows the old page, remove the site's data in Safari and reopen the GitHub Pages URL.
