7位号码预测 PWA
================

这是一个可在 Windows + iPhone 环境使用的 PWA 原型。
它自带 151 期历史数据，并把预测计算放在浏览器本地执行。

Windows 本机启动方式
--------------------
1. 安装 Python 3（如果尚未安装）。
2. 将本文件夹解压到 Windows 任意目录。
3. 在该目录打开 PowerShell 或命令提示符。
4. 运行：
   python server.py
5. 服务器会在电脑局域网地址上提供网页。终端会打印访问地址。
6. 确保电脑和 iPhone 连接同一个 Wi-Fi。
7. 用 iPhone Safari 打开终端打印的 http://电脑IP:8000 地址。
8. Safari 点击“分享” -> “添加到主屏幕”。

以后手机使用
------------
打开主屏幕上的“7位预测”图标，点击“预测下一期”。

录入新一期
----------
在“录入最新开奖结果”中输入期号、日期、7位开奖号码，点保存。
数据会保存在该 iPhone 的浏览器本机 localStorage，并立即重新计算模型。

重要说明
--------
这是统计实验工具，不保证预测中奖。若开奖过程为独立随机过程，历史数据通常不会带来稳定的下一期预测优势。
